# 공수 산정 챗봇

정적 웹앱 형태의 공수 산정 초안입니다.

## 실행

브라우저에서 아래 파일을 직접 열면 됩니다.

```text
C:\Antigravity_PJT\공수산정\effort-estimation\index.html
```

기존 웹사이트에 붙일 때는 `effort-estimation` 폴더를 그대로 배포하고 다음과 같은 URL로 연결하면 됩니다.

```text
/effort-estimation
```

## 현재 포함 기능

- 챗봇형 입력 플로우
- 신규 구성, 메이저 업그레이드, 대개체, 이기종 마이그레이션 분기
- DEV/STG/PRD 체크박스 선택과 대수 입력을 한 화면에서 처리
- DEV/STG/PRD별 상세 공수 표시
- 담당자 기본값은 `락플레이스`
- 첨부 자료 PDF 기준의 상세 공수 산정
- 공수 항목 수정 화면
- 메일 문구 수정 화면
- WBS 항목 수정 화면
- 메일 문구 TXT 다운로드
- WBS 엑셀 호환 파일 다운로드

## 향후 백엔드 연결 시 확장 포인트

- 실제 `.xlsx` WBS 생성
- 산정 이력 저장
- 사용자 로그인/권한 연동
- GitHub 저장소 자동 커밋/배포
- PDF 기준 문서 버전 관리
